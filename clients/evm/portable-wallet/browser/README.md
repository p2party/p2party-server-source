# P2PARTY browser wallet

[Open the wallet on p2party.com](https://p2party.com/wallet/). Choose **Create a wallet** to save an encrypted backup and a separate recovery code. Choose **Restore a wallet** to select or paste your latest backup and enter its code. These are valueless Testnet 1 units. [Create](https://p2party.com/wallet/#create) · [Restore](https://p2party.com/wallet/#restore)

## Receive a payment, including while offline

Share one public receive request with a payer. Save the updated backup each time you add a request. A sender can pay while you are offline. When you return, open the wallet and choose **Check for payments** to find receipts covered by your backup. [Receive P2PARTY](https://p2party.com/wallet/#receive) · [Receiving and recovery help](https://p2party.com/wallet/help/)

## Balance in the wallet and site navigation

The wallet labels a balance with its source and block height. It can verify public history online or import a public snapshot offline. The web wallet offers to show the verified amount under **Account** in your current p2party.com tab. [Open balance](https://p2party.com/wallet/#balance) · [Download public history](https://p2party.com/wallet/snapshot/)

## Rebuild a release

The website repository contains the browser source, build instructions and browser tests. The published downloadable HTML is self-contained. Keep its checksum from a trusted source if you plan to verify your copy offline. This research branch contains the compatible local companion and command-line signer. [Website wallet source](https://github.com/p2party/p2party.com/tree/master/wallet) · [Offline wallet](https://p2party.com/wallet/restore-wallet.html) · [SHA-256 checksums](https://p2party.com/wallet/SHA256SUMS) · [Companion and legacy import](../README.md)
