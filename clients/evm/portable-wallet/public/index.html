Save your recovery kit

Keep the encrypted file and its recovery code in separate places. Anyone with both can spend the units for the requests inside.

  1. Save the encrypted file.

    Choose where to keep it on this device or removable storage.

  2. Keep the recovery code separately.

    Write it down or save it in a trusted password manager.

  3. Check what you saved.

    Choose your downloaded file and enter the code from your separate copy. Your new receive requests will appear after the check.

  4. Open the destination browser.

    On this computer, open this same local address in your other browser. On another computer, start its own companion and open its local address. Choose Restore my wallet, select the file and enter your saved code. Either copy can authorize spending.

Restore my wallet

Choose the encrypted file and enter the separate recovery code. Both stay on this computer.

Close this local wallet

Closing clears this wallet from the running companion. You will need the backup and code to reopen it.
